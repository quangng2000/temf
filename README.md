# TEMF

[Listening demo](https://quangng2000.github.io/temf/): nine examples restored with the **50,000-update EMA checkpoint**, including a [severe synthetic crackling test](https://quangng2000.github.io/temf/#sample-crackling).

Compare **NFE 1, 5, and 20** with original relative levels or RMS-matched playback and log-magnitude spectrograms. Only the synthetic test has a clean reference and STOI scores. Checkpoint and asset hashes are recorded in `results.json`.
