# TEMF

[Listening demo](https://quangng2000.github.io/temf/): eight examples at 20k EMA and a [severe synthetic crackling test](https://quangng2000.github.io/temf/#sample-crackling) at 30k EMA. Includes NFE 1, 5, 20, and 100, original-relative and RMS-matched playback, and log-magnitude spectrograms. Only the synthetic test has a clean reference and STOI scores. Checkpoint and asset hashes are recorded in results.json.
