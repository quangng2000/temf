About this snapshot

Within each example, all restored clips use the same checkpoint and starting noise. The checkpoint is labeled above its outputs. Only NFE changes. Original relative levels are the default. Optional RMS matching matches each clip’s whole-recording RMS to its input, then applies one safety gain within the example. This changes playback loudness only, not model output or restoration quality.

The 325M TEMF model uses frozen Nat conditioning and normalized positional time embeddings. The first eight examples use the exact damaged recordings already used on the RMFSR page, enabling a direct listening comparison. The first eight examples use the 20k checkpoint and have no clean references. The added severe-crackling test uses 30k EMA and includes its clean reference. It is a controlled synthetic example, not a benchmark. More solver steps do not necessarily mean better speech.
